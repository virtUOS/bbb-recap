# Security policy

Please report vulnerabilities privately through GitHub's private vulnerability reporting: on
[github.com/virtUOS/bbb-recap](https://github.com/virtUOS/bbb-recap), open **Security** → **Report a
vulnerability**. Do not open a public issue.

Include what is affected, how to reproduce it and the version or commit. Use synthetic data only; never send
recordings, transcripts or other data of real people.

Fixes are made on the latest release.
